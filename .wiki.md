# Project Summary
IndexBoard helps AI researchers, students, and teams turn model, tool, or method evaluation results into shareable leaderboards. Authors can enter scores and uncertainty intervals, describe their methodology, and publish a read-only board while retaining a private edit key. The home page highlights a pinned board and recent published boards. Authors can also create a board from a written description using AI or start from a template, then review it in the standard editor before publishing.

The app supports English and Chinese, light and dark themes, charts, printing, and JSON exports. Boards are stored in Atoms Cloud.

# Project Module Description
- **Board authoring:** Create or edit boards with a title, description, methodology, metrics, and item results. Enter data in a table, paste JSON/CSV, start from an example, use a template, or generate a draft from a written description.
- **AI board creation:** The create flow’s “Describe it” tab sends one JSON-mode request to the LLM gateway. Results open in the normal editor for review. When the input contains no numbers, the editor marks generated placeholder values with a warning. HTTP 429 and other request or parsing errors receive user-friendly messages.
- **Templates:** One-click starters for LLM leaderboards, paper reproductions, product comparisons, and class or team rankings.
- **Home page discovery:** A featured section pins “Paper Repro Index” first. Recent boards are loaded from the database, newest first, up to nine, excluding the pinned board. Loading, retry, and empty states are provided.
- **Leaderboard and analysis:** View metric charts with interval whiskers, score-versus-cost comparisons, model rankings, and methodology. Overlapping intervals are identified as statistical ties; rankings without intervals are marked provisional.
- **Sharing and access:** Public links are read-only; edits require a private key. Boards can be created without login.
- **Localization and display:** English and Chinese, with light and dark themes.
- **Export:** Print a board, copy or download charts, and download or re-import board data as JSON.
- **Supporting services:** Backend modules provide authentication, database access, storage, settings, health checks, and AI hub integrations.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and reusable UI components.
- **Backend:** Python and FastAPI, with SQLAlchemy and Alembic for database access and migrations.
- **Charts:** Inline SVG charts implemented in the frontend.
- **Cloud services:** Atoms Cloud database and supporting SDK/API integrations; AI board generation uses the LLM gateway without embedding a key in the app.
- **Testing and quality:** ESLint, Playwright configuration, and plugin tests.

# Usage
- Install backend dependencies from `app/backend` with `pip install -r requirements.txt`.
- Install frontend dependencies from `app/frontend` with `npm install`.
- Run frontend linting from `app/frontend` with `npm run lint`.
- Start the frontend development server with `npm run dev`; create a production build with `npm run build`.
- Run the backend using `app/start_app_v2.sh`, or from `app/backend` with the configured ASGI server.
- Apply database migrations from `app/backend` with `alembic upgrade head`.
- Configure the required Atoms Cloud and database settings before running the application.
