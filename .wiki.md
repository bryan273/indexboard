# Project Summary
IndexBoard helps AI researchers, students, and teams turn model, tool, or method evaluation results into shareable leaderboards. Authors can enter scores and uncertainty intervals, describe their methodology, publish a read-only board, and retain a private edit key. The app supports English and Chinese, system light/dark themes, charts, print, and JSON exports.

# Project Module Description
- **Board authoring:** Create or edit boards with a title, description, methodology, and metric results. Enter data in a table, paste JSON/CSV, or start from an example.
- **Leaderboard and analysis:** View metric charts with interval whiskers, a score-versus-cost scatter plot, model rankings, and methodology. Overlapping intervals are identified as statistical ties; rankings without intervals are marked provisional.
- **Sharing and access:** Store boards in Atoms Cloud. Public links are read-only; edits require a private key. Boards can be created without login.
- **Localization and display:** Switch between English and Chinese; light/dark mode follows system preference.
- **Export:** Print a board, copy charts as images or download them, and download or re-import board data as JSON.
- **Supporting services:** Backend modules provide authentication, database access, storage, settings, health checks, and AI hub integrations.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and reusable UI components.
- **Backend:** Python and FastAPI, with SQLAlchemy and Alembic for database access and migrations.
- **Charts:** Inline SVG charts implemented in the frontend.
- **Cloud services:** Atoms Cloud database and supporting SDK/API integrations.
- **Testing and quality:** ESLint, Playwright configuration, and plugin tests.

# Usage
- Install backend dependencies from `app/backend` with `pip install -r requirements.txt`.
- Install frontend dependencies from `app/frontend` with `npm install`.
- Run frontend linting from `app/frontend` with `npm run lint`.
- Start the frontend development server with `npm run dev`; create a production build with `npm run build`.
- Run the backend using `app/start_app_v2.sh`, or from `app/backend` with the configured ASGI server.
- Apply database migrations from `app/backend` with `alembic upgrade head`.
- Configure the required Atoms Cloud and database settings before running the application.
