# Project Summary
IndexBoard is a free tool for AI researchers, students, and teams to turn model, tool, or method evaluation results into a shareable leaderboard. Authors can enter scores and uncertainty intervals, explain their methodology, publish a read-only board, and retain a private edit key. The interface is bilingual, supports system light/dark themes, and offers chart, print, and JSON exports.

# Project Module Description
- **Board authoring:** Create or edit boards with a title, description, methodology, and metric results. Enter data in a table or paste JSON/CSV; load a six-model example to get started.
- **Leaderboard and analysis:** View metric charts with interval whiskers, a score-versus-cost scatter plot, model rankings, and methodology. Overlapping intervals are identified as statistical ties; rankings without intervals are marked provisional.
- **Sharing and access:** Store boards in the Atoms Cloud database. Public links are read-only; edits require the private key. Boards can be created without login.
- **Localization and display:** Switch between English and Chinese; light/dark mode follows the system preference.
- **Export:** Print a board, copy charts as images (or download them if clipboard copying is unavailable), and download or re-import board data as JSON.
- **Supporting services:** Backend modules provide authentication, database access, storage, settings, health checks, and AI hub integrations.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and reusable UI components.
- **Backend:** Python and FastAPI, with SQLAlchemy and Alembic for database access and migrations.
- **Charts:** Inline SVG charts implemented within the frontend.
- **Cloud services:** Atoms Cloud database and supporting SDK/API integrations.
- **Testing and quality:** ESLint, Playwright configuration, and plugin tests.

# Usage
- Install backend dependencies from `app/backend` with `pip install -r requirements.txt`.
- Install frontend dependencies from `app/frontend` with `npm install`.
- Run the frontend development server with `npm run dev`; create a production build with `npm run build`.
- Run the backend using the project startup helper `app/start_app_v2.sh`, or from `app/backend` with the project’s configured ASGI server.
- Apply database migrations from `app/backend` with `alembic upgrade head`.
- Configure the required Atoms Cloud and database settings using the project environment/configuration before running the application.
